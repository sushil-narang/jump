# Risk Profiling Journey Simulator

Static single-page app (HTML + CSS + vanilla JS). No build step, no dependencies.

## Deploy on Vercel
Option A: drag this folder onto https://vercel.com/new (or import it from a Git repo).
  Framework preset: "Other". Build command: none. Output directory: leave empty (root).

Option B: CLI
  npm i -g vercel
  cd risk-journey-simulator
  vercel          # preview
  vercel --prod   # production

## Run locally
Open index.html in a browser, or run `npx serve .` in this folder.
